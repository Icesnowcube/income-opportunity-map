# 输出模板

## A. 发散版：实际地图图片＋文字分析＋机会表

以下是交付结构，不是可直接冒充成品的占位内容。先整理文字与表格，使用生图能力完成图片，再在回复中展示图片和文字；不要把“先图后表”理解为跳过内容核对。

# 【主题】收入可能性地图

**本轮目标：**展开不同交易关系，暂不做个人适配排序。
**已知限制：**【引用用户已给出的限制；没有则写未设】。
**证据边界：**【以下是结构假设；具体案例、政策和收入尚未核验】。

### 地图图片（默认必交付）

- 展示实际生成的主题地图，附真实图片附件或可用的保存入口，优先 PNG。
- 图包含本主题、分类与机会编号、四问框架和代表性交易关系；详细机会表保留为文字。图文一致，未查证的图片也标假设。
- 当前 Agent 没有生图能力时，明确“未生成图片”，以下方文字结构图代替；不得把 Mermaid 源码或提示词当作图片交付。
- 有工具但失败时，标明图片未完成，不使用无生图能力的降级说明。用户明确只要文字时按其范围交付。

## B. 可编辑 Mermaid 版本（补充，不替代默认图片）

下面是可用模板。填入主题与已在表格中定义的编号，不加未出现在正文的新方向。支持 Mermaid 的宿主可以渲染；源码可供后续编辑，但不能因此跳过默认生图。无生图能力时可以交付源码，必须说明未生成图片。

```mermaid
flowchart LR
  ROOT["兴趣 / 能力 / 行业 / 资源"]
  ROOT --> M01["M01 注意力与商业入口"]
  ROOT --> M02["M02 信息、判断与学习"]
  ROOT --> M03["M03 执行与完成结果"]
  ROOT --> M04["M04 产品与作品"]
  ROOT --> M05["M05 授权与复用权利"]
  ROOT --> M06["M06 连接、匹配与交易促成"]
  ROOT --> M07["M07 体验、参与与组织"]
  ROOT --> M08["M08 资源的临时使用权"]
  ROOT --> M09["M09 流通、整合与经营"]
  ROOT -. "另列，性质不同" .-> EXTRA["资本回报 / 补充性报酬"]
```

四问图单独呈现，避免与分类关系混在一起：

```mermaid
flowchart LR
  P["谁付钱"] --> V["他买什么价值"]
  V --> R["我承担什么角色"]
  R --> F["怎样收费"]
```

## D. 查证版

默认配对应机会的证据地图，区分已核验与未知，不扩大为重新发散全图；生图能力与失败处理同 A。

| 机会编号 | 案例 | 交易与收费机制 | 原始来源 / 查证日期 | 地区与资格 | 证据标签 | 未证实的部分 |
|---|---|---|---|---|---|---|

查证“有机制”不等于查证“有人赚到利润”。使用者评价、平台宣传、自报收入、付款记录、本人试用分开解释。

## E. 比较版

默认配比较范围内的对比图；验证模式则配“关键未知 → 行动 → 证据 → 判定”的路径图。生图能力与失败处理同 A。

| 机会编号 | 首笔交易路径 | 资金与资源条件 | 获客依赖 | 持续劳动/责任 | 时间自主与暂停代价 | 最大未知 |
|---|---|---|---|---|---|---|

不强行总分，不在未知时填写精确收入、工时或回本日期。
